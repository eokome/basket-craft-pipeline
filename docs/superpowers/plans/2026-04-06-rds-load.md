# RDS Load Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Allow `extract_load.py` to load raw MySQL tables into AWS RDS Postgres by checking a `TARGET=rds` env var, while keeping local Docker Postgres as the default.

**Architecture:** Modify `get_pg_config()` to branch on `os.environ.get("TARGET")`. When `"rds"`, read `RDS_HOST/RDS_PORT/RDS_USER/RDS_PASSWORD/RDS_DATABASE`. Otherwise, read `PG_*` (unchanged). No new files. Existing tests remain valid.

**Tech Stack:** Python 3, psycopg2-binary, python-dotenv, pytest

def test_get_pg_config_rds_returns_rds_keys():
    env = {
        "TARGET": "rds",
        "RDS_HOST": "rds.example.com",
        "RDS_PORT": "5432",
        "RDS_USER": "rdsuser",

- [ ] **Step 3: Modify `get_pg_config()` in `extract_load.py`**

Replace the current `get_pg_config()` function (lines 20–27) with:

```python
def get_pg_config():
    if os.environ.get("TARGET") == "rds":
        return {
            "host":     os.environ["RDS_HOST"],
            "port":     int(os.environ.get("RDS_PORT", "5432")),
            "user":     os.environ["RDS_USER"],
            "password": os.environ["RDS_PASSWORD"],
            "dbname":   os.environ["RDS_DATABASE"],
        }
    return {
        "host":     os.environ["PG_HOST"],
        "port":     int(os.environ.get("PG_PORT", "5432")),
        "user":     os.environ["PG_USER"],
        "password": os.environ["PG_PASSWORD"],
        "dbname":   os.environ["PG_DB"],
    }
```
